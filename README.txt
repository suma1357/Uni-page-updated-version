NORTHSTAR UNIVERSITY WEBSITE (EDUCATIONAL DEMO)

Files:
- index.html             Home page with fading hero slideshow and seven requested content sections
- about.html             About Us page
- administrations.html   Administration directory
- admission.html          Admission information
- academics.html          Programs, faculties, and research
- notice.html             Notices, events, seminars, and workshops
- style.css               Shared responsive styling
- script.js               Mobile navigation, nested dropdowns, slideshow, program filters

How to run:
1. Extract the ZIP file.
2. Open index.html in a modern browser. For best results, use VS Code with the Live Server extension.
3. Keep all HTML, CSS, and JS files in the same folder.

Notes:
- The site is inspired by the reference university website, but is not an exact copy.
- “Northstar University” is a fictional placeholder. Replace the name, logo, contact details, program information, and demo notices before publishing.
- Photos are loaded from Unsplash over the internet, so an internet connection is required for those images.
- This is a static front-end demo. Forms, official notice downloads, admission submission, and live university data would need backend integration.
